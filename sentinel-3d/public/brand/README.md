# Identidade visual oficial

Coloque aqui **somente** o logotipo oficial, fornecido e autorizado pelo titular da marca:

- `logo.png`: PNG com fundo transparente, proporção original preservada.

Com o arquivo presente, a parede da marca da Recepção passa a exibi-lo (`GET /api/brand`).
Sem ele, a cena mostra uma placa neutra. A plataforma nunca recria nem deforma uma marca.
O `.gitignore` deste diretório impede o versionamento acidental do ativo.
